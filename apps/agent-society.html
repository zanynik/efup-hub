🤝 Agent ↔ Society

"Problems in coding agents map one-to-one with problems in society." — Rochester Row memo, Apr 2026.

From a London walk after an AI-engineering conference: every bug we hit in multi-agent coding systems has a twin in how human society fails to collaborate. Solving one is a glimpse at solving the other.

Why it matters. If protests are "an MVP that ships nothing," and an agent prototype is the same — a quick demo that never solves the real problem — then the discipline we need is identical in both: a design doc up front, modular data handoff, skills instead of one giant context window, and tests that actually verify the work. The tool you'd build for agents is the tool you'd build for groups of humans.
